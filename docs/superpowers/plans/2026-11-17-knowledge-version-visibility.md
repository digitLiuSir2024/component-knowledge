# 组件详情版本可见性修复

用户已要求修复版本不可识别、无法发现待确认更新的问题；不调整人工编辑交互，不提交 Git。

1. 扩展维护 context：返回当前生效版本元信息、正在查看的版本元信息，允许按明确 versionId 读取本组件历史完整详情。新增 drafts/list：系统项目和组件范围内仅 DRAFT 的分页摘要与总数；独立共享对象草稿不作为组件更新。复用既有表，不建表。
2. 全屏详情顶部显示当前或历史版本、确认时间；审核草稿标明基准版本与未生效状态；提供返回当前版本。版本历史标明当前生效及恢复来源，可直接查看历史详情。待确认入口显示总数，列表按更新时间倒序，显示来源、时间、变更数和基准是否已过期，点击复用原位审核。
3. 同步接口文档与前端 README；运行修改范围 Java verify、编译与架构门禁，以及前端格式、类型、lint、已授权现有测试、meta 和 build；浏览器验证当前/历史/草稿切换及控制台。缺少目标浏览器验证如实报告。
